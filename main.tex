\subsection{Instalación de \LaTeX}
%   Las citas se hacen con el comando cite y se colocan justo donde quieres que aparezca la cita, en VSC usualmente la funcion de autocompletado te ayuda a encontrar las referencias en el archivo .bib
Tex es un lenguaje de programación diseñado para diseño y tipografia de documentos, y de manera similar a GIMP o GNU es software gratuito, lo que llevo a la creación de un lenguaje mas fácil de leer y escribir: LaTeX \cite{CTAN}.\\ 
%   El comando href es para hipervinculos, el texto entre llaves es la URL y el texto entre corchetes es el texto que se muestra
Si es preferente seguir las mismas instrucciones que el autor para la instalación es posible encontralaas en esta \href{https://github.com/James-Yu/latex-workshop/wiki/Install}{\underbar{pagina de github}}. \\

En todo caso el primer paso seria instalar VisualStudioCode (ahora abreviado a VSC) y una distribución de TeX, siendo la mas recomendada TeX Live. Para este paso es aconsejable tener una buena conexión puesto que la instalación completa cuenta con 4000+ paquetes individuales y puede tomar de 3 a 4 horas \cite{Lats}.

\subsection{Uso en \LaTeX}
Ya instalado todo deberia ser posible compilar el archivo fuente .tex y obtener un documento similar al adjunto. \LaTeX \textit{workshop} es una extensión muy completa pero algo inestable, especialmente al trabajar con bibliografias y referencias cruzadas, entonces no es de sorprenderse si tu \textit{IDE} se enoja y avienta errores varios al compilar. Lo importante es ver que, aunque haya varias advertencias y errores, si al final el documento se genera tal y como lo quieres, es funcional.\\
