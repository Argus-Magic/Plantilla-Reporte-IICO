# Plantilla-Reporte-IICO
Aqui encontraras dos archivos, un pdf explicando un resumen de como instalar LaTeX para VSCode que sirve tambien como ejemplo de como se ven los documentos escritos usando esta plantilla, y el archivo fuente .tex que genera el pdf. El archivo fuente esta comentado y explicado para aprender que hace cada cosa, ambiente, y comando, para que uno pueda aprender como funciona LaTeX.
## Instalación y lectura
Utiliza el turorial de Jerome Lelong en [Github](https://github.com/James-Yu/latex-workshop/wiki/Install) para instalar LatexWorkshop y poder correr el archivo fuente main.tex para generar el pdf. Igualmente, puedes descargar el pdf con instrucciones simplificadas para la instalacion.
