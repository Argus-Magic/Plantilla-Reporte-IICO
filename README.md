# Plantilla-Reporte-IICO
Aqui encontraras dos archivos, un pdf explicando un resumen de como instalar LaTeX para VSCode que sirve tambien como ejemplo de como se ven los documentos escritos usando esta plantilla, y el archivo fuente .tex que genera el pdf y dos carpetas donde estan los logos y donde irian las imagenes. El archivo fuente esta comentado y explicado para aprender que hace cada cosa, ambiente, y comando, para que uno pueda aprender como funciona LaTeX.
## Instalación y lectura
Utiliza el turorial de Jerome Lelong en [Github](https://github.com/James-Yu/latex-workshop/wiki/Install) para instalar LatexWorkshop y poder correr el archivo fuente main.tex para generar el pdf. Igualmente, puedes descargar el pdf con instrucciones simplificadas para la instalacion.
# Recomendaciones aparte
En un principio imaginé que podría saltar de Word/Docs a Latex directo, pero utilizar VSCode como programa de procesamiento de textos es inadecuado, por decir lo menos, sin importar cuantas extensiones y auto correctores intentes instalar, escribir en Word/Docs es infinitamente más fácil e intuitivo. <br>
Entonces la solución es un compromiso usando las fuerzas de ambos. Para escribir este reporte, yo primero abrí Word y comencé a anotar las secciones y escribir el contenido base del reporte. Ya contento con lo escrito, puedo abrir VSCode e ir programando la plantilla, rellenando los espacios donde irían los párrafos con lo que ya había escrito.<br>
Algunas cosas que también ayudan son comandos como _Alt + Z_ que activa el ajuste de palabras para leer los párrafos escritos mas fácilmente, o los sitios de documentación como Overleaf para saber específicamente cómo funcionan las cosas.
